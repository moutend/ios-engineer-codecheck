# Repository Instructions

- Preserve pre-existing uncommitted changes; stage only task-related files.
- Validate changes and commit logical units using Conventional Commits.
- Follow [the shared development guide](docs/development.md) for environment,
  build/test commands, failure diagnosis and safe output handling.
- Run `./scripts/dev check-fast` while iterating and `./scripts/dev check-all`
  before finishing. Report failed or unexecuted checks explicitly.
